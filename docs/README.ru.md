# vrchat-livetranslate

[![CI](https://github.com/nixi-agent/vrchat-livetranslate/actions/workflows/ci.yml/badge.svg)](https://github.com/nixi-agent/vrchat-livetranslate/actions/workflows/ci.yml)

[![License](https://img.shields.io/badge/license-MIT-green)](../LICENSE)

**Синхронный перевод прямо в VRChat**: захватывает микрофон / звук игры → отправляет в модель
синхронного перевода Qwen Cloud → перевод уходит в **пузырь chatbox** и на
**экран на запястье в VR**; дополнительно можно вернуть переведённый голос в виртуальную
звуковую карту, чтобы **собеседник услышал его напрямую**.

## Язык интерфейса

Интерфейс доступен на **упрощённом китайском**, **English**, **日本語**, **한국어** и **Русском**.
По умолчанию он следует языку Windows, а вручную переключается в **⚙ Настройки**.
**Изменение вступает в силу после перезапуска программы.**

## Что он умеет

| Функция | Статус | Описание |
|---|---|---|
| ① Я говорю → **пузырь chatbox** | ✅ Реализовано, включено по умолчанию | Микрофон → сквозной речевой перевод → первая порция отправляется сразу, дальше снимок каждые 2 секунды, в конце предложения всегда уходит финальная версия |
| ② Говорит собеседник → **экран на запястье** | ✅ Реализовано | Захват вывода воспроизведения VRChat (WASAPI loopback) → перевод (по умолчанию на китайский) → отрисовка в overlay SteamVR. **Как только есть обновление — сразу на экран** |
| ③ Я говорю → **перевод голосом в уши собеседника** | ✅ Реализовано, выключено по умолчанию | Модель сразу отдаёт переведённый звук → ресемплинг в 48 кГц → запись в виртуальную звуковую карту → VRChat забирает это как ваш микрофон. Виртуальную звуковую карту (VoiceMeeter / VB-Cable и т. п.) нужно подготовить самому |
| ④ Я говорю → **ввод с клавиатуры вместо речи** | ✅ Реализовано, включено по умолчанию | Поле ввода внизу окна, **Enter — отправить**: когда не хочется говорить, набирайте текстом. Перевод идёт по **точно такому же** пути, что и в ① (пузырь / экран на запястье); при включённом «Выводе озвучки» он ещё и **озвучивается через TTS** в виртуальную звуковую карту (собеседник слышит) |

## 🙏 Список пожеланий (Wishlist)

Здесь собрано то, **что я хочу увидеть сделанным, но сам не умею / не знаю как / не хочу делать**.
Если что-то из этого похоже на дело, которое вам интересно, — **просто беритесь, спрашивать не нужно**.
Когда закончите, откройте issue или PR, и я прикреплю вашу работу под этим пунктом.

> 📌 **Список постоянно обновляется.** Новые желания добавляются по мере появления, выполненные —
> убираются (или помечаются ✅ с указанием автора). Поставьте звезду репозиторию или заглядывайте иногда.

- [ ] **① Обучающее видео «как этим пользоваться»** — автор любой, **язык любой**
      Сначала установите программу и пройдите всё от начала до конца (достаточно повторить раздел
      «0. Самый быстрый старт»). Затем запишите видео для новичков: как скачать и установить, куда
      вставлять API-ключ и как реально пользоваться этим в VRChat. Подойдёт китайский / English /
      日本語 / 한국어 / Русский — платформа, длина и стиль любые.

- [ ] **② Текстовый туториал со скриншотами** — **язык любой**
      Тоже для новичков: со скриншотами и текстом провести человека по всему пути «от скачивания
      до первого успешного перевода». Подойдёт пост в блоге, страница документации, PDF или длинный тред.

- [ ] **③ Носители языка — вычитать переводы интерфейса** — нужны носители 日本語 / 한국어 / Русский / English
      Интерфейс есть на пяти языках, но японский, корейский и русский списки прошли только машинный
      перевод и одну мою (не носителя) правку — **именно естественность, единообразие вежливой формы и
      единство терминологии может оценить только носитель**. Делается просто: переключите интерфейс на
      свой язык, немного попользуйтесь и откройте issue со скриншотами того, что «переведено неверно /
      звучит неестественно / непонятно». Хотите сразу исправить — `vlt/locales/<язык>.py` это простая
      таблица «китайский оригинал → ваш язык»: правьте её и присылайте PR, **код трогать не нужно**.

Идеальным быть не обязательно — если кто-то после вас не наступит на одни грабли, это уже успех.
