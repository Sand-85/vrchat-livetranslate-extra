# Синхронный перевод в VRChat

[![CI](https://github.com/Sand-85/vrchat-livetranslate-extra/actions/workflows/ci.yml/badge.svg)](https://github.com/Sand-85/vrchat-livetranslate-extra/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/Sand-85/vrchat-livetranslate-extra?label=release)](https://github.com/Sand-85/vrchat-livetranslate-extra/releases/latest)
[![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-blue)](GUIDE.ru.md#1-что-нужно-заранее)
[![Python](https://img.shields.io/badge/python-3.11-blue)](GUIDE.ru.md#1-что-нужно-заранее)
[![License](https://img.shields.io/badge/license-MIT-green)](../LICENSE)

**Синхронный перевод в реальном времени** прямо в VRChat: захват микрофона / звука игры → модель
синхронного перевода 千問雲 (Qwen Cloud) → перевод уходит в **пузырь chatbox** и на **VR-дисплей на
запястье**, а дополнительно переведённый голос можно вернуть в виртуальный микрофон, чтобы собеседник
**слышал его напрямую**.

## 📌 Об этом репозитории

Этот репозиторий — **самостоятельная расширенная сборка**
**[nixi-agent/vrchat-livetranslate](https://github.com/nixi-agent/vrchat-livetranslate)** (MIT),
которую ведёт [@Sand-85](https://github.com/Sand-85): оригинал остаётся нетронутым, а здесь собраны
улучшения, «делающие переведённый голос действительно пригодным к использованию», плюс более смелые
изменения. Репозиторий синхронизируется с оригиналом, большинство возможностей совместимы.
**Основой целиком служит работа автора оригинала [nixi-agent](https://github.com/nixi-agent);
лицензия остаётся MIT (см. `LICENSE`, авторские права принадлежат автору оригинала).**

**Этот репозиторий выпускает только версию для Windows (exe)** — настройки, документация и тесты
ориентированы на Windows; сборка и установка под Linux не поддерживаются.
(Вместе с кодом оригинала сюда попали и Linux-реализация, и `docs/GUIDE.linux.md` — это часть
оригинала, данный репозиторий её не проверяет и ничего по ней не обещает.)

Что добавлено по сравнению с оригиналом:

| Возможность | Описание |
|---|---|
| **Источник озвучки A/B** | Переключается без перезапуска в «Настройки → Перевод: источник и тембр»: **A** — встроенный голос модели реального времени (минимальная задержка) / **B** — локальный потоковый TTS (тембр **полностью совпадает** с режимом набора текстом) |
| **Регулировка темпа речи** | `text_input.tts.speech_rate` (измерено, монотонно). Привязка языка к тембру, бэкенд cosyvoice и прочие детали — в `docs/GUIDE.md` |
| **Исправление: первый раз галочка «Комната» не срабатывала** | Секция `room:` только дописывалась в файл, а конфигурация в памяти не перечитывалась → симптом: «поставил галочку — ничего не происходит, помогает только перезапуск» | (сначала предложено здесь, уже влито в оригинал ✅)

> **Готовая сборка exe — в [Releases](https://github.com/Sand-85/vrchat-livetranslate-extra/releases)**
> (один файл, установка не нужна). Запуск из исходников — см. `docs/GUIDE.md`.

> **Синхронизация с оригиналом**: текущая база — оригинал **v0.6.0**: он влил в основную ветку
> **комнату** (текстовая трансляция на несколько человек, #41), включая наше исправление «первая галочка
> срабатывает сразу» (#5). Внутри же и наше исправление «остановка больше не подвешивает интерфейс»
> с последующими доработками автора (#38 / #40).
> Соответствующая версия этого репозитория — **v0.6.1**; **протокол комнаты теперь общий**, комната
> по-прежнему выключена по умолчанию, и если ею не пользоваться, ничего не меняется.
> Кроме 0.5.x, этот релиз оригинала принёс: вход в комнату переехал в **`⚙ Настройки → Комната`**
> (кнопка подключения/отключения + «случайный» код комнаты), субтитры на рабочем столе показывают ник
> участника комнаты, контекстное меню в поле ввода (вырезать / копировать / вставить / выделить всё)
> и исправление упаковки, чтобы `vlt/room/sinks` точно попадал в артефакт (гейт сверки модулей AppImage).
> Набор 0.5.x тоже внутри: **субтитры на рабочем столе**, поза дисплея по каждой привязке, живой уровень
> входного гейта.
**Этот репозиторий выпускает только версию для Windows (exe)**: столбец Linux в таблице ниже —
возможности, **уже имеющиеся в коде оригинала**; данный репозиторий не собирает, не проверяет и не

## Что он умеет

| Функция | Статус | Описание |
|---|---|---|
| ① Я говорю → **пузырь chatbox** | ✅ Реализовано, включено по умолчанию | Микрофон → сквозной перевод речи → первый инкремент отправляется сразу, затем снимок каждые 2 секунды, в конце предложения всегда отправляется финальная версия |
| ② Говорят другие → **VR-дисплей на запястье** | ✅ Реализовано | Захват вывода VRChat (WASAPI loopback) → перевод на китайский → отрисовка в оверлее SteamVR, **на экран сразу при обновлении** |
| ③ Я говорю → **переведённый голос в уши собеседника** | ✅ Реализовано, выключено по умолчанию | Модель отдаёт переведённый звук напрямую → ресемплинг в 48 кГц → запись в виртуальную звуковую карту → микрофон VRChat его подхватывает. Нужна своя виртуальная звуковая карта (VoiceMeeter / VB-Cable и т. п.) |
| ④ Я говорю → **набор текста вместо речи** | ✅ Реализовано, включено по умолчанию | Поле ввода в нижней строке, **Enter — отправка**: когда говорить не хочется, клавиатура заменяет микрофон. Перевод идёт по **точно такому же** пути, что и в ① (пузырь / дисплей на запястье); если включён «Вывод перевода», он ещё и **озвучивается через TTS** в виртуальную звуковую карту (собеседник слышит) |
| ⑤ Несколько человек → **субтитры друг друга (комната)** | ✅ Реализовано, выключено по умолчанию | Каждый запускает свою копию и вводит **один и тот же код комнаты**; тогда на дисплее на запястье / субтитрах на рабочем столе видно, что говорят остальные. Транслируется только ваша речь (звук игры не передаётся). Вход: `⚙ Настройки → Комната` |

### Поддержка платформ

| Функция | Windows | Linux |
|---|---|---|
| ① пузырь chatbox | ✅ | ✅ |
| ② VR-дисплей на запястье | ✅ оверлей SteamVR | ✅ собственный оверлей OpenXR (Monado / WiVRn) |
| ③ переведённый голос в уши | ✅ нужна своя виртуальная звуковая карта (VoiceMeeter / VB-Cable) | ✅ **не нужна** — приложение само объявляет виртуальный микрофон |
| ④ набор текста вместо речи (с TTS) | ✅ | ✅ |
| ⑤ Комната (субтитры друг друга) | ✅ | ✅ |

Установка и использование в Linux: **[GUIDE.linux.md](GUIDE.linux.md)** ·
Обоснование решений и «какие пути не сработали»: **[docs/平台约束记录.md](平台约束记录.md)** (по-китайски)

> 📌 **Список постоянно пополняется**: новое добавляю, готовое убираю (или помечаю ✅ с указанием
> автора). Если хотите узнавать о новом первым — поставьте Star или заглядывайте иногда.

- [ ] **① Видео-урок «как этим пользоваться»** — кто угодно, **язык любой**
      Сначала установите приложение и прогоните его целиком самостоятельно (достаточно пройти
      [0. Самый быстрый старт](GUIDE.ru.md#0-самый-быстрый-старт-скачать-готовый-exe)), затем запишите
      урок для новичков: как скачать и установить, куда вписать API key и как реально пользоваться этим
      в VRChat. 中文 / English / 日本語 / 한국어 / Русский — любой; платформа, длина и стиль — на ваш вкус.

- [ ] **② Урок с картинками** — **язык любой**
      Для той же аудитории: скриншоты плюс текст, объясняющие путь «от скачивания до первого удачного
      перевода». Подойдёт статья в блоге, страница документации, PDF или длинный пост.

- [ ] **③ Носители языка для вычитки перевода интерфейса** — 日本語 / 한국어 / Русский / English
      Интерфейс есть на пяти языках, но списки слов для японского, корейского и русского сделаны
      машинным переводом плюс одной моей (не носителя) правкой — **естественность, единообразие
      вежливых форм и терминология как раз то, что видит только носитель**. Делается просто:
      переключите интерфейс на свой язык, пользуйтесь им и откройте issue со скриншотами там, где
      «переведено неверно / неестественно / непонятно». Можно и сразу править:
      `vlt/locales/<язык>.py` — это таблица «китайский оригинал → ваш язык», правьте и присылайте PR,
      **кода касаться не нужно**.

Идеальным быть не обязано — если кто-то потом не наступит на одну граблю, это уже успех.
