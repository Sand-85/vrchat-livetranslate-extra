# VRChat 실시간 동시통역

[![CI](https://github.com/Sand-85/vrchat-livetranslate-extra/actions/workflows/ci.yml/badge.svg)](https://github.com/Sand-85/vrchat-livetranslate-extra/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/Sand-85/vrchat-livetranslate-extra?label=release)](https://github.com/Sand-85/vrchat-livetranslate-extra/releases/latest)
[![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-blue)](GUIDE.ko.md#1-사전-준비)
[![Python](https://img.shields.io/badge/python-3.11-blue)](GUIDE.ko.md#1-사전-준비)
[![License](https://img.shields.io/badge/license-MIT-green)](../LICENSE)

VRChat 안에서 **실시간 동시통역**을 합니다: 마이크 / 게임 오디오를 캡처 → 千問雲(Qwen Cloud) 실시간
동시통역 모델로 전달 → 번역문을 **chatbox 말풍선**과 **VR 손목 디스플레이**로 보여 주고, 선택적으로
번역 음성을 가상 마이크로 되돌려 **상대방이 그대로 듣게** 할 수 있습니다.

## 할 수 있는 것

| 기능 | 상태 | 설명 |
|---|---|---|
| ① 내가 말함 → **chatbox 말풍선** | ✅ 구현됨, 기본 켜짐 | 마이크 → 엔드투엔드 음성 번역 → 첫 증분은 즉시 전송, 이후 2초마다 스냅샷, 문장 끝에는 반드시 최종본 전송 |
| ② 상대가 말함 → **VR 손목 디스플레이** | ✅ 구현됨 | VRChat 재생 출력(WASAPI 루프백)을 캡처 → 중국어로 번역 → SteamVR 오버레이에 렌더링, **갱신이 있으면 즉시 표시** |
| ③ 내가 말함 → **번역 음성을 상대 귀에** | ✅ 구현됨, 기본 꺼짐 | 모델이 직접 내보내는 번역 음성 → 48 kHz로 리샘플 → 가상 사운드 카드에 기록 → VRChat 마이크가 받아 감. 가상 사운드 카드(VoiceMeeter / VB-Cable 등)는 직접 준비해야 합니다 |
| ④ 내가 말함 → **타이핑으로 대체** | ✅ 구현됨, 기본 켜짐 | 화면 아래 입력창에서 **Enter로 전송**: 말하고 싶지 않을 때 키보드가 마이크를 대신합니다. 번역문은 ①과 **완전히 같은** 하류(말풍선/손목 디스플레이)를 지납니다. 「번역 음성 출력」을 체크하면 **TTS로 번역문을 읽어** 가상 사운드 카드로 보냅니다(상대가 들을 수 있음) |
| ⑤ 여러 명 → **서로의 자막 보기(룸)** | ✅ 구현됨, 기본 꺼짐 | 각자 이 프로그램을 실행하고 **같은 룸 코드**를 입력하면, 각자의 손목 디스플레이/데스크톱 자막에 **상대가 한 말**이 표시됩니다. 중계되는 것은 자신의 발화뿐(게임 오디오는 전송되지 않음). 입구: `⚙ 설정 → 룸` |

### 플랫폼 지원

| 기능 | Windows | Linux |
|---|---|---|
| ① chatbox 말풍선 | ✅ | ✅ |
| ② VR 손목 디스플레이 | ✅ SteamVR 오버레이 | ✅ 자체 OpenXR 오버레이(Monado / WiVRn) |
| ③ 번역 음성을 상대 귀에 | ✅ 가상 사운드 카드 필요(VoiceMeeter / VB-Cable) | ✅ **불필요** —— 실행 시 스스로 가상 마이크를 선언 |
| ④ 타이핑으로 대체(TTS 포함) | ✅ | ✅ |
| ⑤ 룸(서로의 자막) | ✅ | ✅ |
