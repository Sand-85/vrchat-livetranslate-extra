# VRChat リアルタイム同時通訳

[![CI](https://github.com/Sand-85/vrchat-livetranslate-extra/actions/workflows/ci.yml/badge.svg)](https://github.com/Sand-85/vrchat-livetranslate-extra/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/Sand-85/vrchat-livetranslate-extra?label=release)](https://github.com/Sand-85/vrchat-livetranslate-extra/releases/latest)
[![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-blue)](GUIDE.ja.md#1-前提条件)
[![Python](https://img.shields.io/badge/python-3.11-blue)](GUIDE.ja.md#1-前提条件)
[![License](https://img.shields.io/badge/license-MIT-green)](../LICENSE)

VRChat の中で**リアルタイム同時通訳**を行います：マイク／ゲーム音声を取り込み → 千問雲（Qwen Cloud）
のリアルタイム同時通訳モデルへ → 訳文を **chatbox のバブル**と **VR リストディスプレイ**に表示し、
オプションで訳音声を仮想マイクへ戻して**相手にそのまま聞かせる**こともできます。

## 📌 このリポジトリについて

本リポジトリは **[nixi-agent/vrchat-livetranslate](https://github.com/nixi-agent/vrchat-livetranslate)**
（MIT）の**独立した強化版**で、[@Sand-85](https://github.com/Sand-85) がメンテナンスしています ——
上流はそのままに、こちらでは「訳音声を実際に使えるようにする」ための強化と、さらに踏み込んだ変更を
まとめて管理しています。上流と同期しながら更新しており、機能の多くは両方で共通です。
**土台はすべて原作者 [nixi-agent](https://github.com/nixi-agent) の成果物です。ライセンスは MIT を
継承します（`LICENSE` 参照、著作権は原作者に帰属します）。**

**本リポジトリが配布するのは Windows 版（exe）のみです**。設定・ドキュメント・テストはいずれも
Windows 基準で、Linux のビルドやインストールはサポートしません。
（上流のコードに伴って Linux 側の実装と `docs/GUIDE.linux.md` も入っていますが、それは上流のもので、
本リポジトリは検証も保証もしていません。）

上流に対して追加されている部分：

| 機能 | 説明 |
|---|---|
| **音声翻訳の音源 A/B** | 「設定 → 翻訳音声：音源と声色」で再起動なしに切り替え：**A** リアルタイムモデル内蔵の声（遅延最小）／**B** ローカルのストリーミング TTS（声色はタイピング翻訳と**完全に同一**） |
| **話速の調整** | `text_input.tts.speech_rate`（実測で単調に効く）。声色の言語固定や cosyvoice バックエンドなどの詳細は `docs/GUIDE.md` |
| **修正：ルームの初回チェックが効かない** | `room:` セクションをファイルに書き足すだけで、メモリ上の設定を読み直していなかった → 「ルームにチェックしても無反応、再起動すると直る」という症状 | （本リポジトリが先に出し、upstream にマージ済み ✅）

> **ビルド済み exe は [Releases](https://github.com/Sand-85/vrchat-livetranslate-extra/releases)**（単一ファイル・
> インストール不要）にあります。ソースから実行する場合は `docs/GUIDE.md` を参照してください。

> **upstream との同期**：現在のベースは upstream **v0.6.0** —— upstream が**ルーム**（複数人での
> テキスト中継）を本線にマージしました（#41。本リポジトリが先に提出した「初回チェックで即時有効」の
> 修正 #5 も含みます）。「停止してもフリーズしなくなった」修正と作者による後続改善も入っています（#38 / #40）。
> 本リポジトリの対応バージョンは **v0.6.1**。**ルームのプロトコルは両者で同一**になり、既定では無効です
> （使わなければ影響はありません）。
> 0.5.x からさらに、ルームの入口が **`⚙ 設定 → ルーム`** に移動（接続/切断ボタン + ルームコードの
> 「ランダム生成」）、デスクトップ字幕がルーム参加者のニックネームを表示、テキスト入力欄の右クリックメニュー
> （切り取り／コピー／貼り付け／すべて選択）、そして `vlt/room/sinks` を確実に成果物へ入れるパッケージ修正
> （AppImage のモジュール照合ゲート）が入っています。
> 0.5.x の分も同梱：**デスクトップ字幕**、リスト位置のアンカー別保存、入力ゲートのリアルタイム表示。
**本リポジトリは Windows 版（exe）のみを配布します**：下のプラットフォーム表の Linux 列は
**上流のコードが元々備えている機能**であり、本リポジトリはビルド・検証・保証を行いません（理由は上記）。
両者の `config.yaml` は同じ意味を持ちます。

## できること

| 機能 | 状態 | 説明 |
|---|---|---|
| ① 自分の発話 → **chatbox のバブル** | ✅ 実装済み・既定で有効 | マイク → エンドツーエンド音声翻訳 → 最初の増分は即送信、その後 2 秒ごとにスナップショット、文末は必ず最終版を送信 |
| ② 相手の発話 → **VR リストディスプレイ** | ✅ 実装済み | VRChat の再生出力（WASAPI ループバック）を取り込み → 中国語に翻訳 → SteamVR オーバーレイに描画、**更新があれば即座に表示** |
| ③ 自分の発話 → **訳音声を相手の耳へ** | ✅ 実装済み・既定で無効 | モデルが直接出力する訳音声 → 48 kHz にリサンプル → 仮想サウンドカードへ書き込み → VRChat のマイクが拾う。仮想サウンドカード（VoiceMeeter / VB-Cable など）は自前で用意してください |
| ④ 自分の発話 → **タイピングで代用** | ✅ 実装済み・既定で有効 | 画面下の入力欄で **Enter を押せば送信**：話したくないときはキーボードをマイク代わりに。訳文は①と**まったく同じ**下流（バブル／リストディスプレイ）を通ります。「翻訳音声の出力」にチェックが入っていれば、**TTS で訳文を読み上げて**仮想サウンドカードへ送ります（相手に聞こえます） |
| ⑤ 複数人 → **お互いの字幕を見る（ルーム）** | ✅ 実装済み・既定で無効 | 各自が本プログラムを起動し**同じルームコード**を入力すると、それぞれのリストディスプレイ／デスクトップ字幕に**相手の話した内容**が表示されます。中継されるのは自分の発話のみ（ゲーム音声は転送されません）。入口：`⚙ 設定 → ルーム` |

### 対応プラットフォーム

| 機能 | Windows | Linux |
|---|---|---|
| ① chatbox のバブル | ✅ | ✅ |
| ② VR リストディスプレイ | ✅ SteamVR オーバーレイ | ✅ 自前の OpenXR オーバーレイ（Monado / WiVRn） |
| ③ 訳音声を相手の耳へ | ✅ 仮想サウンドカードが必要（VoiceMeeter / VB-Cable） | ✅ **不要**（実行時に自分で仮想マイクを宣言します） |
| ④ タイピングで代用（TTS 含む） | ✅ | ✅ |
| ⑤ ルーム（お互いの字幕） | ✅ | ✅ |

Linux のインストールと使い方：**[GUIDE.linux.md](GUIDE.linux.md)** ・
設計の根拠と「試して通らなかった道」：**[docs/平台约束记录.md](平台约束记录.md)**（中国語）

      `vlt/locales/<言語>.py` が「中国語原文 → あなたの言語」の対応表なので、そこを直して PR を
      送るだけです（**コードには触りません**）。
