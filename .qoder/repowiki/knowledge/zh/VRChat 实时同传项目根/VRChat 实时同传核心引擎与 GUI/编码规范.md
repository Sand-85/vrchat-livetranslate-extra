- 配置值校验统一采用「非法值留痕 + 回落默认」策略，通过 `_cfg_bool` / `_cfg_pos_float` / `_warn_default` 等辅助函数打印 `[config] ⚠️ ...` 日志后返回默认值，绝不静默带病运行。
- API key 读取遵循固定优先级：显式参数 → 界面保存（按 slot 分槽）→ `DASHSCOPE_API_KEY` 环境变量 → `~/.bailian/config.json`，来源以掩码形式打日志便于排查。
- 专有词库合并走单一入口 `merge_hotwords`（全局 glossary + 方向级 hotwords），避免实时会话与打字翻译两条腿出现口径漂移。
- 会话实现通过 `session/base.LiveTranslateSession` 抽象接口暴露 `start/send_audio/close` 与 `TextDelta` 事件，新模型代次只需新增实现类并在 `create_session` 中按 model 前缀分发。
- 所有对外 CLI/GUI 入口使用 `from __future__ import annotations` 并以 `argparse` 解析参数，错误路径统一 `print(..., flush=True)` 而非抛异常，保证可交互场景下用户能看到提示。
