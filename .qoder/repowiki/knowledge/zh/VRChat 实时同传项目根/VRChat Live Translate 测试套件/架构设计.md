扁平目录，每个被测模块对应一个 `test_*.py` 文件；测试通过 `sys.path.insert(0, ...)` 把仓库根加入 import 路径后直接 `from vlt.*` 导入被测对象。
- 无头逻辑用例（engine、virtualmic、config_save、paths、i18n、repeat_guard、silence_gate、wrap、textin、devices、device_pick、crashlog_stamp、log_rotation、loopback_teardown）用标准 `def test_*()` + `assert`，可被 pytest 或 `if __name__ == "__main__"` 直跑。
- GUI 用例（test_update_dialog.py、test_overlay_steamvr.py、test_overlay_conversation.py、test_gui_rows.py、test_chatbox_direction.py、test_api_key_gui.py）基于 tkinter，构造 `TranslationGUI` 实例并断言窗口控件状态。
- 外部依赖一律打桩：网络请求、`subprocess.Popen`、Tkinter messagebox、系统语言检测、音频设备 API 均通过临时替换模块属性注入假实现，避免真实 I/O。
- 大型 GUI 测试集中在 `test_update_dialog.py`，按「弹窗→下载进度→完成态→重载/稍后/退出时替换→AppImage→版本变更提示」分阶段组织，并用 `_frozen_env` / `_appimage_env` / `_stub_popen` 三个 contextmanager 隔离 exe/AppImage 运行形态。
