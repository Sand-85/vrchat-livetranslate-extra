根目录作为应用的装配点：`run_gui.py` 是 PyInstaller 的冻结入口，负责在导入 `vlt.gui` 前兜底 `sys.stdout/stderr`、拦截 `--verify-*` 自测参数并转发到 `vlt.selfcheck`；`requirements.txt` 集中声明跨平台公共依赖（python-osc、Pillow、websockets、numpy、sounddevice、miniaudio、PyYAML），Windows/Linux 独占依赖则拆到 `requirements-windows.txt` / `requirements-linux.txt`；`config.example.yaml` 是首次启动时复制为 `config.yaml` 的配置模板，被 vlt_app 的 config 模块加载后驱动 session/capture/directions/chatbox/overlay/desktop_overlay/output/text_input/room/ui 等所有子模块行为。顶层 `.bat` 脚本（`run_chatbox.bat`、`run_overlay.bat`、`run_selfcheck.bat`、`build_exe.bat`、`install_secret_guard.bat`、`setup.bat`）分别对应独立子程序、打包、凭据扫描与安装流程，由 scripts 子模块实现。tests 通过 pytest 直接 import vlt 包进行单元测试，docs 提供多语言用户指南，三者均依赖根级 requirements 与 config 约定。
