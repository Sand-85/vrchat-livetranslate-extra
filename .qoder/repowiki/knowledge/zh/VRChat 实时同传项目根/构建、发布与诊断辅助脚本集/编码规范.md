- 脚本入口统一使用 `if __name__ == "__main__": raise SystemExit(main())` 形式返回退出码，便于 CI 判定。
- 需要 API Key 的脚本通过 `load_api_key()` 从 `DASHSCOPE_API_KEY` 环境变量或 `~/.bailian/config.json` 读取，且从不打印明文 key。
- 诊断类脚本通过 `sys.path.insert(0, str(Path(__file__).resolve().parent))` 再 `from probe_realtime import load_api_key` 复用公共密钥读取逻辑，避免重复实现。
- 对外部命令（git、gh、PyInstaller、pyinstxtractor-ng）一律用 `subprocess.run(..., capture_output=True, text=True, encoding="utf-8", errors="replace")` 调用并以 returncode 判断成败。
- 日志输出到仓库根 `logs/` 目录，文件名带时间戳（如 `probe_YYYYMMDD_HHMMSS.jsonl`），失败路径也会 dump 已收集的事件以便排障。
