脚本按职责平铺在 scripts/ 下，无子包，彼此通过 `sys.path.insert(0, ...)` 共享 `probe_realtime.load_api_key` 这一 API Key 读取逻辑。
- 构建与发布：`build_exe.py` 调用 PyInstaller 把 `run_gui.py` 打包为单文件无控制台 exe，内置 HIDDEN/COLLECT_ALL/EXCLUDE_WIN 列表以处理按需导入和平台独占模块；`verify_release.py` 独立复核已发布的 Release 附件（sha256 vs GitHub digest、--self-test、版本行、字节码 needle、图标像素比对）。
- 安全门禁：`check_no_secrets.py` 作为 pre-commit hook 扫描暂存区，匹配阿里云/GitHub/AWS/Bearer/token 等正则模式并白名单放行占位符。
- 接口探针：`probe_realtime.py` 是核心（WebSocket 握手 + session.update + PCM 推送 + 事件计时），被 `probe_endpoints.py`、`probe_session_update.py`、`probe_session_update2.py` 复用其 `load_api_key` 做不同 URL / session 载荷矩阵的连通性诊断。
- OSC 调试：`osc_listen.py` 用 socket+struct 解析 UDP OSC 报文，校验 chatbox 的 `,sTT` typetag 约束。
依赖方向单向：诊断脚本 → probe_realtime → websockets；构建/发布脚本不依赖诊断脚本。
